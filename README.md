# صانع الشعر العربي الفصيح 🖋️✨

تطبيق ويب ذكي ومتكامل لنظم الشعر العربي الفصيح، ومحاكاة كبار الشعراء، ومعارضة القصائد الشهيرة، وتشريحها عروضياً وبلاغياً باستخدام أحدث تقنيات الذكاء الاصطناعي (نماذج عائلة Gemini 2.0 / 1.5).

تتميز البنية البرمجية الحالية بأنها مهيأة بالكامل للنشر السحابي السلس والآمن على **Cloudflare Pages** باستخدام تقنية **Cloudflare Pages Functions (Serverless)**، مما يعزل مفاتيح الـ API تماماً عن الواجهة الأمامية ويمنع تسريبها.

---

## 🚀 دليل النشر على منصة Cloudflare Pages

لقد تم إعداد وهيكلة المشروع ليعمل بأفضل ممارسات الأداء والحماية على Cloudflare Pages. للبدء بالنشر، اتبع الخطوات البسيطة التالية:

### 1. ربط المشروع بـ Cloudflare
1. قم بتسجيل الدخول إلى حسابك في [Cloudflare Dashboard](https://dash.cloudflare.com).
2. انتقل إلى القسم الخاص بـ **Workers & Pages** ثم اضغط على **Create application**.
3. اختر تبويب **Pages** واضغط على **Connect to Git** لربط مستودع GitHub الخاص بك.

### 2. إعدادات البناء والتشغيل (Build Settings)
عند تحديد مستودع المشروع، قم بتهيئة إعدادات البناء بالشكل التالي:

* **Framework Preset:** `Vite` (أو اتركه `None`)
* **Build Command:** `npm run build`
* **Build Output Directory:** `dist`
* **Root Directory:** `/` (الجذر)

### 3. إعداد متغيرات البيئة (Environment Variables)
لحماية مفتاح الذكاء الاصطناعي، يستدعي التطبيق الخادم السحابي الآمن عبر الدالة الكاشفة `functions/api/[[catchall]].ts`. يتوجب عليك تهيئة المتغير التالي في لوحة تحكم Cloudflare Pages:

1. في إعدادات مشروع Pages، اذهب إلى تبويب **Settings** ثم **Environment variables**.
2. تحت قسم **Production** (وكذلك **Preview** إن أردت)، اضغط على **Add variable**.
3. قم بإضافة المتغير التالي:
   * **Variable Name:** `GEMINI_API_KEY`
   * **Value:** *(ضع مفتاح Gemini API الخاص بك هنا بشكل سري)*
4. اضغط على **Save** ثم أعد نشر المشروع (Redeploy).

## 🛠️ البنية الهيكلية والتقنية للمشروع

يتبع التطبيق نمط الفصل الكامل بين العرض والأمان:
* **واجهة العرض (Frontend):** مبنية باستخدام React 19 و Vite و Tailwind CSS لضمان سرعة فائقة وتصميم متجاوب راقٍ ومريح للعين.
* **الخلفية السحابية (Cloudflare Functions):** تتواجد في المجلد `/functions` حيث تستقبل الطلبات بشكل آمن وتمررها لمنطق المعالجة المتطور دون الكشف عن أي مفاتيح تشغيلية.
* **منطق الذكاء والـ Parsing:** يتواجد في الملف المستقل الموحد `/src/backend-logic.ts` الذي يتعامل مع النماذج، ويصلح النصوص والمخرجات العشوائية عبر خوارزميات تصحيح JSON ذاتية لضمان استقرار الاستجابة.

## 💻 التشغيل المحلي والتطوير

إذا كنت ترغب في تشغيل التطبيق محلياً للتطوير:

1. قم بتثبيت الاعتماديات:
   ```bash
   npm install
   ```

2. أنشئ ملف المتغيرات المحلية `.env` في جذر المشروع وأضف مفتاحك:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

3. شغّل خادم التطوير المحلي الهجين:
   ```bash
   npm run dev
   ```
   سيقوم هذا الخادم بتشغيل Express مع واجهة Vite بشكل متناغم على المنفذ `3000`.
